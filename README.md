# 3-in-1 Calculator

A simple web-based calculator with:

- Normal calculator
- Scientific calculator
- Date of birth age calculator

## Run it locally

Open `index.html` in a browser.

## Files

- `index.html` - app structure
- `style.css` - styles
- `script.js` - calculator logic

## Features

- Basic arithmetic operations
- Scientific functions like `sin`, `cos`, `tan`, `log`, square root, power
- Age calculation based on date of birth

## Preview

This project is designed to run as a static web page without any dependencies.
